# Jey Oil Export Intelligence

Portable full-stack package for export market intelligence, financial feasibility, route/Incoterm evaluation, risk analysis and portfolio optimization for Jey Oil Refinery.

## Included

- React / Next.js / TypeScript frontend
- Python FastAPI service
- PostgreSQL data model
- Docker Compose one-command local deployment
- Managed database schemas and migrations
- Real country-border world map data
- NPV, IRR, payback and scenario engines
- Risk, competitor and portfolio modules
- PDF pre-feasibility report generator
- Standalone offline HTML calculator
- Demonstration data clearly separated from live-source data

## Quick start

```bash
docker compose up --build
```

Open `http://localhost:3000`. API documentation is available at `http://localhost:8000/docs`.

See `INSTALL_FA.md` for Persian instructions. Live ITC Trade Map, Export Potential Map, Market Access Map and ePing data require authorized access or validated source exports. No licensed credentials are included.
